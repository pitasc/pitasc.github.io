========================
skill_guarded_lin_ruckig
========================

Causes a linear motion with the ruckig trajectory generator
until a specified force value is
reached

Defined at line 243 of file :doc:`skills/skill_ruckig.xml <../model_files/pitasc_library/skills/skill_ruckig_xml>` in package **pitasc_library**.

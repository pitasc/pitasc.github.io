===================
Realworld tutorials
===================

.. rst-class:: tutorial-meta

:bdg-primary:`Hands-on` :bdg-secondary:`Force control`
:bdg-secondary:`3D-printed setups` :bdg-info:`Real hardware`

These tutorials take you from a bare robot to a working, force-controlled
application. Every parkour is built from 3D-printed parts, so you can reproduce
the whole setup on your own hardware.

Before you start
================

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Requirement
     - Details
   * - Robot
     - Any pitasc-compatible robot with a force/torque sensor.
   * - Gripper
     - Weiss WSG 50-110, Robotiq 2F-85 / 2F-140 or Franka Hand.
   * - 3D printer
     - For the parkour parts. Tolerances tested on a Bambu Lab X1.
   * - Workbench
     - Welding table with 50 × 50 hole pattern (recommended).

.. danger::
   Always **tare the force/torque sensor** before running force-controlled
   skills, and keep the emergency stop within reach.

.. tip::
   Add **user confirms** between skills while developing. They make it far
   easier to spot problems and abort execution safely.

This tutorial provides a practical introduction on how to develop pitasc
applications using examples you can follow **without prior experience** with
pitasc. The documentation includes training courses with detailed information
about the requirements, setup, and completion of the tutorial parkour courses.


What you will learn
===================

.. grid:: 1 2 2 3
   :gutter: 3

   .. grid-item-card:: :octicon:`tools` Setup
      :link: setup
      :link-type: doc

      Install pitasc, prepare the workspace and verify your toolchain.

   .. grid-item-card:: :octicon:`beaker` Simulation
      :link: simulation
      :link-type: doc

      Run the parkour courses in simulation before touching real hardware.

   .. grid-item-card:: :octicon:`rocket` Real world
      :link: real_world
      :link-type: doc

      Transfer your application to a physical robot and run the parkour.

Requirements
============

.. list-table::
   :header-rows: 1
   :widths: 25 35 40

   * - Category
     - Requirement
     - Notes
   * - OS
     - Ubuntu 20.04 / 22.04
     - Other distributions untested
   * - ROS
     - Noetic
     - Must be sourced before starting
   * - Hardware
     - UR robot + guide fixture
     - Optional – simulation works standalone

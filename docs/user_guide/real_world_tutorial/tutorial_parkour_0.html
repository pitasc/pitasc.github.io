Simple Maze – Cartesian Space

What you will learn

How to use several of pitasc’s most common skills, including linear movements, a guarded approach and different ways of using the slide skill.

Level: beginner Cartesian space force control ~60 min setup

Setup

Step 1 - Print the parts

Print the lower and upper section, the cylindrical peg carrier and the cylindrical peg. Also as per your gripper, print the custom gripper fingers to hold the cylindrical peg.

Warning

Tolerances were tested on a Bambu Lab X1 - adjust if needed..

Step 2 - Assemble the station

Assemble the lower and upper section using the screws and nuts.

Step 3 - Clamp everything to the table

Clamp the assembled station and the workpiece carrier to your table.

Step 4 - Position the cylindrical peg on the peg holder

Place the cylindrical peg in the peg holder as shown below.

Step 5 - Mount the gripper fingers

If needed, screw the custom 3D-printed gripper fingers onto the Weiss WSG 50-110 gripper.

How to solve this parkour task

The task is to solve a maze using a cylindrical peg, as shown in the video below.

Try it yourself

You can try to solve the task on your own by selecting appropriate skills and teaching the required poses.

Where to put your solution

Add your solution to:

.../pitasc_realworld_tutorial_p0/apps/parkour_0.xml

Then start RViz and the frame editor with:

roslaunch pitasc_realworld_tutorial_p0 bringup_ur5_parkour_0.launch

Increasing levels of assistance

The following sections progressively reveal more detail. Stop reading at whichever level still leaves you with an interesting challenge.

  1. Level 1 – Rough steps - the three high-level actions

  2. Level 2 – Example steps in detail - every individual motion, no code

  3. Level 3 – Tips on using skills - which pitasc skills to reach for

  4. Level 4 – Step-by-step sample solution - the full annotated XML

Level 1 – Rough steps

The sample solution comprises the following rough steps. Each step is implemented as a skill sequence containing several skills:

  1. Pick up the rod from the holder.

  2. Solve the maze by moving from the start position to the end position.

  3. Place the rod back into the holder.

Level 2 – Example steps in detail

Note

For safety reasons, each step begins and ends with the robot moving to its home pose by linear movement.

Step 1 - Pick up the rod from the holder

  1. Move to home pose (position controlled)

  2. Move to a position above the workpiece carrier (position controlled)

  3. Lower the end effector to the gripping position (position controlled)

  4. Grip the rod (command to your specific gripper)

  5. Push down on the rod to ensure a safe grip (force controlled - only needed for flat gripper fingers)

  6. Move upwards (position controlled)

  7. Move to home pose (position controlled)

Step 2 - Solve the maze

  1. Move to home pose with the rod between the gripper fingers (position controlled)

  2. Move linearly to a hover position above the maze (position controlled)

  3. Move to the approach position close to the maze start point (position controlled)

  4. Establish contact between rod and maze (force controlled)

  5. Slide the rod through the maze while keeping a constant force of at least 5 N between rod and maze (force controlled).

    Warning

    Write this skill without hardcoding the maze waypoints.

    Note

    The example code moves the robot so that the rod reaches the goal position by utilising rod–wall interactions. The walls along the slot can be used to guide the rod using force feedback.

  6. Once the rod reaches the goal position, the skill ends and the end effector moves upwards.

  7. Move to home pose (position controlled)

Step 3 - Place the rod back into the holder

  1. Move to home pose (position controlled)

  2. Move to a position above the workpiece carrier (position controlled)

  3. Place the rod in the holder by pushing down with a force of e.g. 10 N (force controlled)

  4. Open the gripper to release the rod (command to your specific gripper)

  5. Move back up to the pre-grasp pose (position controlled)

  6. Move to home pose (position controlled)

Level 3 – Tips on using skills

Goal

Recommended approach

Establish contact with the surroundings

Use a guarded approach.

Predictable linear motion with minimal jerk

Use lin_time_optimal_ruckig.

Follow a wall under constant force

Use the pitasc slide skill.

End a skill on a condition

Attach monitors to react to a force threshold or travelled distance.

Danger

Always tare the force/torque sensor before running force-controlled skills.

Tip

Add user confirms between skills. This makes it much easier to spot problems and abort execution safely while developing.

Level 4 – Step-by-step sample solution

Preamble

The preamble handles all imports of relevant models and configures the application environment, in which every component (robots, sensors, actuators) must be specified in order to be controlled later on. It also defines a boolean parameter to activate or deactivate all user confirmations at once.

0_preamble.xml
<?xml version="1.0" encoding="UTF-8"?>

<pitasc>
    <models>
        <!-- Include relevant models -->
        <include package="pitasc_library" file="models/pitasc.xml"/>
        <include package="pitasc_library" file="models/skills.xml"/>
        <include package="pitasc_library" file="utils/gravity_compensator.xml"/>
        <include package="pitasc_library" file="universal_robots/ur.xml"/>
        <include package="pitasc_library" file="weiss_robotics/kms40.xml"/>
        <include package="pitasc_weiss_wsg" file="models/wsg50.xml"/>
        <include package="pitasc_library" file="frame_editor/frame_editor.xml"/>
        <include package="pitasc_library" file="frame_editor/frame_editor.xml" />
        <include package="package_door_opening" file="scripts/script_temp_frame_offset.xml"/>
        <include package="pitasc_webinar" file="skills/skill_solve_puzzle.xml"/>
    </models>

    <!-- Create an application -->
    <clone prototype="project">

        <!-- Parameter to ignore all user confirms. If set to True, all user
        confirms are skipped. If set to False, all user confirms are active -->
        <type id="ignore_uc" prototype="bool_parameter">
            <meta>
                <member id="description">Parameter to ignore user confirms (uc) and fire the (success) event immediately</member>
                <member id="visibility">basic</member>
            </meta>
            <data>False</data>
        </type>

        <!-- Configure pitasc (set update rate, relevant for controllers)-->
        <member id="configuration">
        <clone id="configuration" prototype="default_configuration">
            <member id="update_rate">250</member>
        </clone>
        </member>

        <!-- Set up environment -->
        <member id="environment">
            <!-- Specify and configure robot -->
            <clone id="ur5" prototype="robot_ur5">
                <member id="robot_driver.max_velocity">0.4</member>
                <member id="robot_driver.max_acceleration">1.0</member>
                <member id="robot_driver.topic_in">ur5/joint_states</member>
                <member id="robot_driver.topic_out">ur5/joint_vel</member>
                <member id="robot_driver.urdf_key">ur5/robot_description</member>
